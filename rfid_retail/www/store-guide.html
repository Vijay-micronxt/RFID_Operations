How to run the RFID store

Every garment carries a small RFID tag. Put the garment on the counter tray and the bill fills itself. Pick your job below and follow the steps.

ManagerOne-time setup Stock staffReceive, tag, count CashierBilling and payment

First, four words

Tag

A small sticker with a chip on the garment. Each has a code. After a sale the same tag goes on a new garment.

Tray

The reader plate on the counter. Put garments on it and it reads all tags at once.

Shift

The counter's working day. Open it in the morning with the drawer cash, close it at night and count.

Station /rfid

The page on a phone or PC where tags are put on, taken off and stock is counted.

Manager

Switch RFID on

Search in the desk: RFID Settings
  1. Tick Enable RFID. Nothing works without it.
  2. In Station access choose who does what. The default is fine: cashier bills, stock staff tag, manager does everything.
  3. Give every User a role: RFID Cashier, RFID Stock Operator or RFID Store Manager. Cashiers also get POSNext Cashier.

Set up the counter

POS Profile, RFID Device, POS Settings
  1. Open the POS Profile: fill warehouse, walk-in customer, payments (Cash, UPI, Card). Add the cashiers under Applicable for Users.
  2. Tick RFID Counter on the same profile.
  3. Create an RFID Device: type Tray Reader, linked to this POS Profile.
  4. In POS Settings tick Tax Inclusive (MRP already includes GST).

The reader works like a barcode scanner. Plug it in, nothing to install.

Which items carry tags

Item (set it on the template, all sizes and colours follow)
  1. Tick RFID Tracked Garment. That is enough.
  2. For a set (suit = jacket + trouser): tick Has Serial No and list the pieces in a Garment Set Definition. A set sells only when every piece is at the counter.

Stock already in the store has no tags. It all shows in the station's To tag list. Tag it there before the first sale.

Put tags on (the easy way)

Same submitted document → RFID Tags
  1. Pick the row, e.g. Formal Shirt Red 40 (12 pieces).
  2. Put on 12 tags and hold them all on the reader together. Any tag can go on any piece.
  3. Green tags are fine. A red one is bad or already used: take it off, use another.
  4. It saves by itself when the count is right. Leftovers can be tagged later.

Read tags on the wrong row? Use Check stickers / move tags in the same dialog. No cancel needed.

Tag at the station

/rfid → To tag
  1. The list shows how many pieces of each item still need a tag: old stock, returns.
  2. Pick the item (or scan its barcode), hold all its tags on the reader. Count right, saved.
  3. Sets and returns go one by one: the screen asks for each piece's tag.

Tag history tab: read any tag to see its full story: which garment, who sold it, for how much.

Daily stock count

/rfid → Stock count
  1. Pick the warehouse, press Start today's count.
  2. Walk the floor with the handheld and scan every tag. Each piece gets ticked.
  3. Finish count & show result: what was found, what is missing.
  4. Send for review. A manager checks it. Counting never changes stock.

  3. Type the cash in the drawer, then Open Shift.

"Existing Shift Found" means yesterday's shift is still open. Press Resume Shift or Close & Open New.

Billing: garments on the tray

  1. Put all the customer's garments on the tray. They appear in the cart.
  2. Orange box = set incomplete (jacket read, trouser not). Put the missing piece on the tray. Payment waits.
  3. Red line = this tag cannot be sold. Put the garment aside and tell the manager.
  4. Type the customer's mobile or name (or leave walk-in), then Checkout.

Do not click a tagged garment in the item list. The system blocks it or asks. Always use the tray.

Tag will not read? Tick Tag unreadable - scanning printed labels and scan the sticker's barcode.

Take payment

  1. Pick Cash, UPI or Card. Half cash, half UPI also works.
  2. Remaining must be ₹ 0. Extra cash shows as Change Due: give it back.
  3. Press Pay, then Print Invoice. Done. Tags are freed by themselves.

Customer stepped away? Press Hold. Open it later from Draft Invoices.

Customer returns a garment

  1. Press Return Invoice, find the old bill by number or mobile.
  2. Tick the returned garment and its quantity.
  3. Choose how to refund (cash/UPI), Create Return.

Hand the returned garment to stock staff. They check it and re-tag it at the station before it sells again.

Evening: close the shift

  3. Balanced = all correct. Short = less. Over = more. Then Close Shift and print the report.

If you see this, do this

Most mistakes are fixed without cancelling anything.

Tag … belongs to a garment that is already sold.

The old tag was never freed. Remove it at /rfid → Remove tags, put a new one.

… is not a known tag or label.

This garment was never tagged. Tag it at Station → To tag.

A set on the tray is incomplete.

Put the missing piece on the tray too, or Remove the set.

… is in Stores - B, not this counter's warehouse.

The garment belongs to another warehouse. Transfer the stock first.

Tag … is marked Damaged. Put a new tag on this garment.

Manager puts a new tag on from Tag history.

No tray panel at all

Manager checks: RFID Counter ✓ on the POS Profile, you hold the Billing station, then reload.

Only one of many tags read

Place the garments a little slower and read again.

Need to cancel a purchase

Ask a manager. Cancelling takes the stock back out and a warning lists the tags that go free. For a wrong tag, do not cancel: fix the tag instead.

Something not covered here? Ask your store manager.
